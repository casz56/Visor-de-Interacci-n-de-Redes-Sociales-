# INFIHUILA · Dashboard Plan de Medios

Versión actualizada con logo institucional incrustado para GitHub Pages, gráficos interactivos y KPI graficables funcionales.

## Mejoras incluidas

- Logo INFIHUILA embebido en Base64 para evitar errores de ruta al publicar en GitHub Pages.
- Filtros de plataforma, período, indicadores y modo gráfico.
- Nuevas tortas KPI funcionales en español latino:
  - Torta de tasa de interacción: mide interacciones logradas frente a la meta del 4% sobre visualizaciones.
  - Torta de conversión a clics: mide clics generados frente a la meta mínima de CTR del 0,20%.
- Semáforo gerencial editable desde el aplicativo:
  - Agregar alertas.
  - Borrar alertas.
  - Editar título, descripción y nivel de alerta.
  - Recalcular alertas automáticas.
- Ruta de mejora editable desde el aplicativo:
  - Agregar recomendaciones.
  - Borrar recomendaciones.
  - Editar texto directamente.
- Carga de PDF, Excel, XLS y CSV.
- Exportación CSV.

## Publicación en GitHub Pages

Sube todos los archivos de esta carpeta al repositorio y publica desde GitHub Pages. El logo no depende de archivos externos porque está incrustado en el HTML/JavaScript.
